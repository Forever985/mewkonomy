# MewKonomy 使用说明书（面向玩家）

> 本文面向**普通玩家用户**，教你如何把本工具跑起来、看懂主界面，并逐页说明每个功能怎么用。
> 不需要任何编程知识。若你只是想用，读到「五、常见问题」即可。

---

## 一、这是什么？

MewKonomy（原 Milkonomy，牛牛放置利润计算）是一个 **Milky Way Idle 银河放置**游戏的**本地自用利润计算工具**。

- **纯本地运行**：不收集、不上传你的任何数据，无后端、无账号；游戏数据来自项目自带的 `data.json` / `market.json`（线上部署版会自动拉取站点上由定时任务更新的数据文件，详见 §4.10 的历史采样说明）。
- **主要用途**：算清楚「做什么最赚钱」——哪个装备值得强化、哪条产业链利润最高、哪个护符转化最划算、市场里什么物品成交量最大。
- **运行方式**：在本机启动一个网页（http://localhost:xxxx），用浏览器打开即可使用。

> 注意：本工具展示的价格为游戏**市场快照**（一个时间点的挂单/收购价），并非实时价格；计算结果随数据刷新而变化。

## 二、如何启动

### 2.1 准备工作（只需一次）

1. 安装 [Node.js](https://nodejs.org/)（建议 18+）。
2. 安装包管理器 pnpm（Node.js 自带 npm，可在命令行执行 `npm install -g pnpm`）。
3. 打开命令行，进入项目文件夹：
   ```
   cd D:\milkonomy\milkonomy-main
   ```
4. 安装依赖（首次运行需要，会花几分钟）：
   ```
   pnpm install
   ```

### 2.2 启动工具

在项目文件夹内执行：

```
pnpm dev
```

等命令行出现本地地址（形如 `http://localhost:5173/`），用浏览器打开即可。

- 默认 `pnpm dev` 会以 **private（私有完整）模式**运行，你能看到全部页面。
- 若只想体验公开版内容，可执行 `pnpm dev:public`。

### 2.3 多语言切换

主界面右上角有语言切换按钮，支持 **简体中文 / English**。切换后界面文案即时生效，无需重启。

## 三、主界面与布局

- **顶部/侧边导航**：所有功能页面都从导航进入，按「计算」「打野」「产业链」等用途分组。
- **玩家配置区（首页顶部）**：计算利润需要知道你的「个人情况」，首页顶部集中设置（详见四.1）。
- **价格来源标识**：每页结果都会标注价格取自哪里，详见「五、如何理解价格来源」。

## 四、逐页功能说明

### 4.1 首页 / 玩家配置（Dashboard）

首页顶部是全局玩家配置，**所有页面的计算都受这里影响**：

| 配置项 | 说明 |
| --- | --- |
| 玩家等级 / 行动等级 | 各生活技能的等级，用于判断「所需等级」是否达标 |
| 装备配置 | 你身上的装备（含强化等级），影响实际采集/制作效率 |
| 茶品配置 | 勾选已喝的茶（如工匠茶、智慧茶等），会获得等效等级加成 |
| 社区增益 | 勾选已解锁的社区 buff |
| 每小时时间价值 | 你给「1 小时游戏时间」估的价，用于把时间成本折算进利润 |
| 手动价格 / 单价覆盖 | 对某些物品手动指定价格，覆盖市场价 |
| 自动刷新 | 自动拉取最新市场数据 |

> 提示：工匠茶勾选后，「装备要求等级」会 +5（如 80→85），页面会用红色标出你当前等级达不到要求的装备。

首页主体是**利润网检索**：按条件筛出「做什么最赚钱」的方案列表，支持：

- **多物品多选**：一次选多个物品/条件并行检索；
- **组合条件**：添加多行条件（如「目标等级 OR 某个制作项目」）并行匹配；
- **等级 / 利润率 / 风险区间双头筛选**：设置最小值~最大值范围；
- **排除开关**：排除装备、排除首饰、排除战斗装备、排除生活装备；
- **收藏 / 筛选 / 排序 / 翻页**：星标收藏常用方案，按利润率/风险等排序，分页浏览（分页状态会记住）。

### 4.2 强化计算（Enhancer）

- **功能**：算「把某件装备强化到指定等级（如 +10）值不值得」。
- **操作**：搜索并选中一件装备 → 设置目标强化等级、材料买价口径、成品卖价口径 → 查看强化成本、成功率、预计利润。
- **说明**：可结合「分解回收」收益一起看总账（进入强化分解页可进一步看分解利润）。

### 4.3 强化分解（Enhanposer）

- **功能**：把「强化 + 分解回收」整条链路一起算，回答「买装备强化到 X 再分解，赚不赚」。
- **搜索区**：同样支持多物品/组合条件/等级/利润率/风险区间筛选，以及排除战斗/生活装备开关。
- **子模式**：
  - **不分解模式**：只算「强化」这一段的利润，不叠加分解收益；
  - **价格源**：成品按「左挂单(ask)」还是「右收购(bid)」计价——左挂单是你挂出去卖给别人能拿到的价，右收购是别人收购单的价，二者行情不同。
- **注意**：负利润方案也会显示（方便你看清哪些是坑），不可用的方案会被跳过。

### 4.4 超级强化计算（Enhancest）

- **功能**：面向高端玩法的「超级强化」计算器，针对可超级强化的装备，精细核算每一档的材料成本与成品售价。
- **操作**：搜索选中装备 → 设置强化等级、材料买价/成品卖价口径 → 查看各强化档位明细（含保护卷、逃逸体等成本）。
- **特点**：比普通强化计算更细，逐项列出材料与保护花费；成品/材料价格口径可独立切换。

### 4.5 超级强化分解（Enhanposest）

- **功能**：超级强化装备的「强化 + 分解」组合计算，回答「超级强化到 X 再分解是否划算」。
- **搜索区**：与强化分解页一致的多条件筛选 + 排除战斗/生活装备开关。
- **说明**：不可用（无法强化/分解）的方案会跳过，负利润方案同样会列出。

### 4.6 打野工具组（打野 / 超级打野 / 制作强化 / 继承 / 分解 / 捡漏）

导航里「打野」一组的多个页面，围绕野外刷取物品的收益优化：

| 页面 | 功能 |
| --- | --- |
| 打野工具（Jungle） | 算野外采集/刷怪掉落的物品「捡到后卖多少」，评估打野路线收益 |
| 超级打野（Junglest） | 打野工具的进阶版，支持更细的条件（多物品、等级区间等） |
| 制作强化（Junglerit） | 针对打野产出的装备/材料做「制作+强化」收益计算 |
| 继承（Inherit） | 算装备强化等级继承/转移的成本与取舍 |
| 分解（Decompose） | 算把装备分解成材料是否划算（回收价值 vs 售价） |
| 捡漏（Pickout） | 在市场中找「挂单价明显低于估值」的低价物品，帮助扫货 |

> 各页操作逻辑一致：选物品 → 设条件 → 看结果表格，支持排序与翻页。

### 4.7 制作炼金（Manualchemy）

- **功能**：把「采集 → 制作 → 炼金」的生产线算成利润，回答「用哪些材料做什么最赚」。
- **操作**：检索制作/炼金项目 → 设置目标等级、利润率/风险区间 → 查看每条生产线的利润排行。
- **说明**：支持多物品/多条件并行检索；「要求等级」会随工匠茶勾选 +5 并标红提示。

### 4.8 手动产业链（Chainbuilder）

- **功能**：**自由拼接多步产业链**，从原材料一路到成品，算整条链的总利润。
- **操作**：
  1. 点「+ 添加步骤」增加环节，每个环节选「项目（专业）+ 物品 + 催化剂等级」；
  2. 用上移/下移调整环节顺序（比如先采集原料，再制造，最后炼金）；
  3. 给链起个名字，点「计算」查看每步的成本、产出与整链利润率。
- **特点**：比固定模板更灵活，适合自己设计冷门产业链；存在不可用环节时会提示你检查。

### 4.9 护符转化盈利（Charmtransform）

- **功能**：算「把护符（charm）转化为其他道具/护符」是否划算。
- **操作**：选转化来源与目标 → 选择转化等级/次数 → 查看转化成本、成功率与预期收益。
- **说明**：适合大量积压护符时评估「转化 vs 直接卖」哪个更赚。

### 4.10 市场监控（Marketvolume）

- **功能**：按**市场成交量/成交额**给所有物品实时排行，帮你发现「什么在被人大量买卖」。
- **顶部摘要**：市场物品总数、有成交数量、成交量最高物品。
- **筛选**：关键词搜索、按分类过滤；默认只显示**有成交**的物品（避免大量无成交量条目干扰）。
- **排序**：可对成交量、成交额、价格、买/卖价、物品等级等列排序（升/降）。
- **翻页**：每页 50 条，避免 3000+ 条目一次性渲染卡顿。
- **涨跌监控**：表格「涨跌」列（**红涨绿跌**）用**时间窗**（1/3/6/12/24/72/168 小时）对比「时间窗起点前最近一次历史采样」算出涨跌百分比；「对比口径」下拉可切换按 **价格（买卖价中点）/ 左挂单 / 右收购 / 成交量（速率）** 计算，切换即时重算。另有「成交量/小时」列显示成交量速率。
- **方向筛选**：可按「全部 / 上涨 / 下跌 / 持平」过滤，顶部实时显示涨 / 跌 / 平各多少条。
- **历史采样**：涨跌依赖历史价格采样——每次打开本页自动采样一次，也可点**「立即采样」**手动记录（本地兜底节流 30 分钟一条、最多保留 200 条、滚动 7 天）；线上部署版还会自动加载服务端 7 天历史归档（每 20 分钟一个采样点、最多 520 点）。所选时间窗内无历史采样时，该行涨跌列显示「--」。
- **注意**：成交量是官方**当日累计成交量**（每天 UTC 0 点归零），所以「成交量」口径比的是**增量速率**而不是绝对量；跨过归零点的窗口会显示「--」。成交量来自市场数据快照，若某物品成交量为 0，可能确实没人交易，也可能是本地缓存了旧数据（见常见问题）。

## 五、如何理解「价格来源」

计算结果里的价格，可能来自三个渠道，页面会按物品标注来源：

| 来源 | 含义 | 可信度 |
| --- | --- | --- |
| **真实市场价** | 市场快照中真实存在的挂单/收购价 | 最可信，随数据刷新变化 |
| **兜底价** | 该物品市场上**完全没有交易记录**时，用「卖商店价」(sellPrice) 兜底 | 仅供参考，可能偏离实际 |
| **自产/自定价** | 你在玩家配置里手动指定的价格，或估算的自产成本 | 取决于你的输入 |

- **左挂单 (ask)** = 你把物品挂单出售给他人能拿到的价格；
- **右收购 (bid)** = 他人挂出的收购单价（你把物品直接卖给收购单的价格）。
- 强化/分解计算里，「材料/成本」通常按 ask 算，「成品/收益」通常按 bid 算；部分页面（强化分解、超级强化）允许你切换成品计价口径。

> 小贴士：如果某装备查不到任何价格，说明市场里近期没人交易，页面会用兜底价让你至少能看到一个估算。

## 六、常见问题（FAQ）

**Q1：页面打不开 / 白屏？**
确认命令行里 `pnpm dev` 已成功启动、浏览器访问的是命令行提示的地址（不是双击 html）。

**Q2：价格好旧 / 不对？**
价格来自市场快照。可在首页顶部点击刷新/自动刷新拉取最新数据；若某物品价格异常为 0，见 Q4。

**Q3：收藏、筛选条件、分页会自动保存吗？**
会。工具会在浏览器本地记住你的配置（收藏、筛选条件、翻页位置等），下次打开还在。

**Q4：市场监控里很多物品成交量全是 0？**
先确认市场数据是否最新（刷新）。若刷新后仍为 0，可能是浏览器本地缓存的旧数据导致，清空该站点浏览器缓存后重新打开即可（开发者在「强化分解/市场监控」处已对旧缓存做兼容处理，正常会自动清除）。

**Q5：为什么有的装备在「排除战斗装备」和「排除生活装备」里都被排除？**
该装备同时带战斗与生活属性（both 类），两个开关都会把它过滤掉。想看到它，两个开关都别勾。

**Q6：负利润的方案为什么还显示？**
为方便你判断「哪些是坑」，负利润方案也会列出（可自行按利润率排序看正负）。完全不可用的方案才会跳过。

**Q7：数据会上传/联网吗？**
不会上传你的任何数据。工具无后端、无账号，数据文件随项目提供；线上部署版的站点数据由 GitHub 定时任务自动更新（见 §4.10）。
